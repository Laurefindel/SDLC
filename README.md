## InternetLifeApp

**Автор:** Хута Е. В.

**Дисциплина:** Жизненный цикл разработки программного обеспечения

**Название проекта:** «Сколько ты проживёшь в интернете»

### Описание проекта

InternetLifeApp — настольное приложение, разрабатываемое
на языке C# с использованием Windows Forms.

Приложение предназначено для расчёта времени, которое
пользователь предположительно проводит в интернете в течение
жизни, на основе количества часов, проводимых в интернете
ежедневно.

В дальнейшем приложение будет рассчитывать количество лет,
проведённых в интернете, приблизительное количество
просмотренных мемов и пролистанной рекламы и предоставлять
результаты через графический интерфейс пользователя.

В проекте планируется использовать архитектурный шаблон MVC.
